## Deliberate deviation from the supplied directive

The directive requested a wholesale replacement and an `App.tsx` provider-detection snippet. The repository already had a newer, tested provider router and a gated-FLUX fallback commit on `main`. I therefore made the narrower change that preserves existing routing contracts and tests while moving image generation to a deterministic ungated model. This avoids duplicate provider logic and avoids accidentally regressing the existing DeepSeek/WebGPU behavior.

The launcher also does not blindly kill every `llama-server` process. It reuses a healthy endpoint and scopes stale-process cleanup to the exact configured server binary and port. This is intentional shell hardening: a repair script should not disrupt unrelated local inference services.
